# 새 기믹(변형 요소) 추가하기

**결론: 파일 하나만 추가하면 되는 게 아니다.** 기믹이 "퍼즐의 정답을 제약하는지",
"데일리 로테이션에 넣을지"에 따라 손대야 할 곳이 달라진다. 아래 체크리스트 순서대로.

부등호(`inequality`) · 연속(`consecutive`) · 스네이크(`snake`) · 턴테이블(`turntable`)이
현재 있는 4개다. 새 기믹의 `type` 문자열(예: `killer`)을 정하고 시작한다.

---

## A. 항상 필요 (렌더링만 되면 끝인 순수 표시용 기믹도 포함)

| # | 파일 | 할 일 |
|---|---|---|
| 1 | `src/structures/<Name>.js` | `Structure` 상속 클래스. 생성자에서 `super('<type>', coords)`, 필요한 원시 필드 저장. `validate(board)` 가 규칙 위반 시 위반 좌표 배열 반환(위반 없으면 `[]`). 순수 표시용이면 `validate(){ return []; }` (턴테이블 참고) |
| 2 | `src/puzzles/reviveStructures.js` | `switch (s.type)` 에 `case '<type>': return new <Name>(...)` 추가. 데일리 JSON은 평문이라 이걸로만 되살아난다 |
| 3 | `src/ui/BoardRenderer.js` | `render()` 안에서 `board.structures.filter(s => s.type === '<type>')` 로 골라 SVG 마크를 그림. 기존 `inequality`/`snake` 그리는 부분을 찾아 그 옆에 추가 |
| 4 | `src/main.js` `createPickerState()` | `elements: { …, '<type>': 'none' }` 에 키 추가 (자유 연습 선택기가 이 객체를 그대로 씀) |

## B. 정답을 제약하는 기믹이면 추가로 (부등호·연속·스네이크처럼)

순수 표시용(턴테이블)이면 건너뛴다.

| # | 파일 | 할 일 |
|---|---|---|
| 5 | `src/generator/composeTemplate.js` | `ELEMENT_KEYS`, `ELEMENT_LABELS` 에 추가. `COVERAGE_RATIO_BY_AMOUNT` 또는 `scaledCount` 등 "양(normal/many)" 규칙 정의. `buildTemplateFromSelection()` 에서 `resolved.elements['<type>'] !== 'none'` 일 때 `rules.push({ type: '<type>', region, … })` |
| 6 | `src/generator/deriveRules.js` `deriveRuleStructures()` | `else if (rule.type === '<type>')` 분기 추가 — **완성된 해를 보고** 실제 구조체를 만든다(부등호가 `va>vb` 보고 방향 정하듯). 값을 해 채우기 **전에** 못박아야 하는 종류면(스네이크처럼) `prefill…()` 진입점을 따로 만들고 `generatePuzzle.js` 의 `tryGenerate()` 에서 호출 |
| 7 | `src/generator/backtrack.js` `makeCheckers()` | "값을 놓은 뒤 판정 가능한" 제약이면 체커 추가. `fillRandomSolution`/`countSolutions` 가 이걸로 해를 만들고 유일해를 센다 |
| 8 | `src/generator/logicSolver.js` | 사람이 논리로 푸는 방식을 가르친다. **안 하면** `carveGivens(requireLogicSolvable:true)` 가 그 제약을 못 써서 given 을 너무 많이 지우거나 생성이 실패한다 |
| 9 | `src/generator/peerIndex.js` `buildExtraStructureIndex()` | 인접/관계형 제약이면 `s.type !== …` 필터에 `'<type>'` 추가 |
| 10 | `src/generator/snakeWalk.js` | 스네이크처럼 "영역 안에서 경로/묶음"을 뽑아야 하는 종류만 |

## 최소 케이스 요약

- **순수 표시용 기믹** (규칙 없음): A(1·2·3·4)만. 데일리에 넣으면 C 도.
- **정답 제약 기믹**: A + B 전부. 데일리에 넣으면 C + D 도.
- 딱 "파일 하나 추가"로 끝나는 경우는 없다.

## 검증

1. `node scripts/generate-daily.mjs 2099-01-01 1` 로 새 요소가 들어간 퍼즐이 생성되는지
2. `src/generator/solveBoard.js` 로 그 퍼즐이 저장된 solution 과 **유일하게** 일치하는지
3. 로컬에서 자유 연습 → 새 요소 선택 → 생성·플레이, 콘솔 에러 0
4. 데일리 익스텐디드에서 사이드바 책갈피 아이콘/설명 확인
